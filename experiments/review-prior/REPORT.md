# Historical publication-claim review — 2026-11-15

This ledger reviews earlier drafts of `experiments/whitepaper/parano1d-audit.typ`
and `experiments/FINDINGS.md` against the pinned target and saved lane results.
Quoted wording and line numbers refer to those drafts as read on this date;
the current paper and findings supersede them. The review tested claim scope,
not network behavior. `TAKEOVER.md` had identified the HeaderDAG-height error;
this table records related corrections and additional evidence boundaries.
The phase-8 release-node control was completed after this review and is
reported separately in `devnet-chaos/PHASE8_REVIEW.md`.

## Editorial and data notes from the draft review

- The abstract says 39 of 43 lanes delivered results; the table text says five lanes were added while drafting. Preserve a reproducible lane-count basis when revising the table. (The C25 row appears once; overlapping read ranges initially made it appear twice.)
- Whitepaper :223 says the far-future timestamp “defeats” the genesis pin. The attack fork still must **share genesis and carry real PoW**; timestamp manipulation targets later difficulty. Say it satisfies the genesis pin by mining a fork from it.
- Whitepaper :215 says “Four DNS names are the entire internet bootstrap” without a default-config qualifier. The node supports explicit seeds, persisted peers, and LAN discovery. State “the default clean-install internet seeds.”
- “GUI users have no defense surface at all” (:235) is stronger than shown. They can choose a different release, inspect/replace the node process, or use alternate software. The shipped GUI does not expose a switch to disable default DNS seeds.
- A release signature or checksum addresses channel substitution only when its trust anchor is independent of the distributed artifact. The C16 pack issue requires control of standalone-builder input bytes.
- State the measured transaction, history, and wallet boundaries directly. Separate executed local outcomes from release-verifier and live-network questions.
